# Docs

How things work, and how to do them. One topic per file, named after the
subject: `deploy-to-staging.md`, `auth.md`, `onboarding.md`.

Nothing here is precious. If a doc is wrong, fix it — the version you replaced
is still in the project's history, and `bdrive log <file>` will show you who
changed it and when.

Delete this file once there are real docs beside it.
