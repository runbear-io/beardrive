# Archives

Everything finished, cancelled, or superseded — moved here whole, unchanged,
with one line at the top of its README saying what happened and when.

This is not a wastebasket. It is what makes "have we tried this before?"
answerable, and it stays searchable like the rest of the project. Nothing here
is deleted, and anything still being cited belongs back in `resources/`.
